#  CALCULADORA - CÉSAR ANGOS

## 2. Descripción general

El proyecto consiste en el desarrollo de una calculadora digital que permite al usuario realizar operaciones aritméticas de manera sencilla, rápida e intuitiva.

La aplicación cuenta con una interfaz gráfica que facilita la interacción mediante botones numéricos y operadores matemáticos. Su propósito es proporcionar una herramienta funcional para resolver cálculos cotidianos y aplicar los conocimientos adquiridos en programación orientada a objetos y desarrollo de aplicaciones de escritorio.

## 3. Objetivos

### Objetivo general

Desarrollar una aplicación de escritorio utilizando C# y Windows Forms que permita realizar operaciones matemáticas básicas mediante una interfaz gráfica amigable.

### Objetivos específicos

- Implementar operaciones aritméticas básicas.
- Diseñar una interfaz gráfica intuitiva y organizada.
- Aplicar los fundamentos de programación en C#.
- Gestionar los eventos asociados a los botones de la calculadora.
- Facilitar la interacción entre el usuario y la aplicación.

## 4. Características principales

La calculadora incorpora las siguientes funcionalidades:

- **Suma (+):** permite sumar dos valores numéricos.
- **Resta (-):** permite calcular la diferencia entre dos valores.
- **Multiplicación (*):** permite multiplicar dos números.
- **División (/):** permite dividir dos valores numéricos.
- **Números del 0 al 9:** permiten ingresar los valores para las operaciones.
- **Botón C:** permite limpiar la pantalla de la calculadora.
- **Botón igual (=):** permite mostrar el resultado de la operación.

## 5. Tecnologías utilizadas



 C#  Lenguaje de programación utilizado. 
 .NET Framework  Plataforma de desarrollo de la aplicación. 

 Visual Studio Entorno de desarrollo integrado (IDE). 

 GitHub  Plataforma de alojamiento del código fuente. 

## 6. Requisitos de instalación

Para ejecutar correctamente el proyecto se necesita:

- Sistema operativo Windows.
- Visual Studio con soporte para desarrollo de escritorio con .NET.
- Componente de desarrollo de escritorio con .NET Framework.
- .NET Framework 4.7.2 o una versión compatible.
- Git para clonar el repositorio.

## 7. Instrucciones de ejecución

### 7.1. Clonar el repositorio

Abrir PowerShell o CMD y ejecutar:

```bash
git clone https://github.com/CesarAngos/Cal.git
```

### 7.2. Ingresar al directorio

```bash
cd Cal
```

### 7.3. Abrir el proyecto

1. Localizar el archivo `Calculadora.csproj`.
2. Abrirlo utilizando Visual Studio.
3. Esperar a que se carguen los componentes y dependencias del proyecto.

### 7.4. Ejecutar la aplicación

1. buscar el archivo calculadora.exe en la carpeta debug.
2. Presionar el botón Iniciar .
3. Esperar a que aparezca la ventana de la calculadora.

## 8. Estructura del proyecto

La estructura principal del proyecto es la siguiente:

```text
Cal/
│
├── Properties/
│   ├── AssemblyInfo.cs
│   ├── Resources.resx
│   ├── Resources.Designer.cs
│   └── Settings.settings
│
├── App.config
├── Calculadora.csproj
├── Form1.cs
├── Form1.Designer.cs
├── Form1.resx
├── Program.cs
│
├── README.md
└── .gitignore
```

### Descripción de los archivos principales

- **App.config:** contiene configuraciones de la aplicación.
- **Calculadora.csproj:** archivo de configuración del proyecto.
- **Form1.cs:** contiene la lógica y los eventos de la calculadora.
- **Form1.Designer.cs:** contiene la configuración de los controles de la interfaz gráfica.
- **Form1.resx:** almacena los recursos del formulario.
- **Program.cs:** contiene el punto de entrada de la aplicación.
- **Properties/:** almacena propiedades y recursos del proyecto.
- **README.md:** contiene la documentación general del proyecto.
- **.gitignore:** especifica los archivos que no deben incluirse en el repositorio.
